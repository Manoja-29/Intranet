# Intranet – Attendance Management System

An internal attendance and employee management system built using PHP with an MVC architecture.

## Features

- Employee management
- User authentication and login
- Attendance management
- Holiday and leave management
- Employee records
- Payroll management
- MVC-based application structure

## Architecture

The application follows an MVC architecture:

- `model/` – Database and application data logic
- `controller/` – Application controllers and request handling
- `view/` – User interface
- `includes/` – Shared application components
- `src/` – Supporting source files

## Technologies

- PHP
- MySQL
- Bootstrap
- JavaScript
- HTML5
- CSS3
- MVC Architecture
